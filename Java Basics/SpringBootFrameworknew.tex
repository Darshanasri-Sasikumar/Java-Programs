Day1:SpringBoot Introduction:
-----------------------------
        1.Why Spring Boot?
            Traditionally,Before building an Application,There will we several setup to build an Enterprice application such as
               ->Dependecy
               ->Server Configuration
               ->Application Configuration
               ->Database Configuration
               ->Onject creation and dependency Injection

        what is meant by Standalone Application?
        Standalone application can run independently with out any external server or container.

    1.Definition:
     ----------
    Spring Boot is a JavaBased Framework build top on spring Framework that simplifies the development of standalone 
    
    2.Spring VS Spring Boot:
    ----------------------
        Spring Framework	                     Spring Boot
           
            More manual configuration	         Less manual configuration
            Dependencies managed individually	 Starter dependencies
            Server setup can be separate	     Embedded server support
            More initial setup	                 Faster project setup

    3.Important Features of Spring Boot:
    ---------------------------------
            1.Autoconfiguration
            2.Standalone Applications
            3.Embedded Server Support
            4.Production-ready features


    @SpringBootApplication Annotation:
    -------------------------------
            ->It is the main Annotation used for start point and enables important application features
            ->It is a combination of three annotations
                1.@Configuration
                2.@EnableAutoConfiguration
                3.@ComponentScan

    @RestController Annotation:
    ------------------------------- 
                ->It is used communicate with the client and server using RESTful web services.
                ->It is a combination of controller and response body
            Difference between @Controller and @RestController:
            ------------------------------------------
                ->COntroller is used to return default view page
                ->Controller is used for MVC architecture
                ->Needs Response body for Direct data

                ->Restcontroller is used for RestAPI's
                ->Returns direct data
                ->It is a combination of controller and response body
