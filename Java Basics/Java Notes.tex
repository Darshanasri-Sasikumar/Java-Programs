Compiler time checks for the syntax
A compiler error happens before running the program, while compiling.

Runtime:
Run time error occurs during thr execution of the program
It occurs when Java checks your code for syntax rules.


Static method can override?
No - static method cannot overiide because override occurs during run time

what happens when a constructor calls an override method?
When a constructor calls an overridden method, the child’s overridden method executes due to dynamic binding, but the child’s fields may not be initialized yet, so it can give wrong output or NullPointerException.
